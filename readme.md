# Asistente de pre-atención para administración de consorcios

TP Integrador — Microcredencial #2: Diseño de Aplicaciones Inteligentes (Instituto de Tecnología ORT)

## Caso elegido

**Administración Ombú** (caso ficticio) administra 38 consorcios en CABA y recibe unos 250 mensajes diarios por WhatsApp y mail: reclamos de mantenimiento, consultas de expensas, reservas del SUM y trámites. Hoy se atienden a mano. El proyecto diseña un asistente de pre-atención que **interpreta** esos mensajes con un LLM y **resuelve** con reglas y datos reales del sistema de gestión. La IA es el intérprete y la base de datos es la autoridad.
