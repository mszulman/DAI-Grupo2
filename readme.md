# Asistente de reclamos de mantenimiento para administración de consorcios

TP Integrador — Microcredencial #2: Diseño de Aplicaciones Inteligentes (Instituto de Tecnología ORT)

## Caso elegido

**Administración Ombú** (caso ficticio) administra 38 consorcios en CABA y recibe unos 250 mensajes diarios por WhatsApp. Desde la Entrega 2, el proyecto se concentra en los **reclamos por reparaciones** (~90 por día: ascensores, filtraciones, luces, puertas), que hoy se cargan a mano, con muchos duplicados y emergencias que se pierden entre reclamos comunes. El asistente **interpreta** cada mensaje con un LLM y **resuelve** con reglas y datos reales. La IA es el intérprete y la base de datos es la autoridad.
